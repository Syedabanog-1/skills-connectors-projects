# Portable Study Notes Skill

Use this skill whenever processing lecture notes, technical meeting transcripts, or course materials.

## Execution Rules
1. Organize key topics into clean Markdown H2 headings.
2. Under each heading, summarize main takeaways with **key terms highlighted in bold**.
3. Conclude the document with an `## Executive Review Questions` section containing **EXACTLY THREE** questions testing knowledge retention.
4. Output no conversational preamble or metadata comments.
